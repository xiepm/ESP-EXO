## 静态架构标准

- 控制任务采用静态 TCB 和静态栈，只创建一次；
- LEFT/RIGHT 共用同一个任务和周期时间基准；
- `impedance_control.c` 不存在周期 `esp_timer`；
- 旧阻抗 tick 只有唯一控制任务一个周期调用者；
- 新控制模块不包含 `EXO_ACTUATOR_A/B`、CAN ID 或直接 CAN 发送；
- 控制周期没有日志、动态分配、阻塞延时和状态机；
- 周期运动发送使用零等待 TX mutex、零等待 TWAI 入队且失败不打印日志；
- `imp_start/imp_stop` 不创建、删除或重启控制任务；
- `app_main()` 只初始化并返回。

## 时序通过标准

空闲及旧阻抗运行两种条件分别检查：

| 指标 | 通过标准 |
|---|---:|
| 连续观察时间 | 至少 5 分钟 |
| 平均周期 | `10.0 ms +/- 0.1 ms` |
| 目标范围内周期 | 至少 99% 位于 `9-11 ms` |
| 最大周期误差 | 不超过 `2 ms` |
| 最大单周期执行时间 | 小于 `10 ms` |
| Deadline miss | `0` |
| 快速补跑/CAN 突发 | 不出现 |
| 静态任务栈最低余量 | 不低于初始栈的 25% |

`control_status` 是按需诊断，不属于阶段 10 连续遥测。LEFT/RIGHT 各自保留反馈
来源时间戳，阶段 4 不要求严格同步采样。执行时间覆盖本周期主要工作和局部诊断
更新；计时后只剩固定长度的完整快照原子发布。

## 功能回归标准

1. 上电后任务周期计数持续增加，但不自动使能电机；
2. A/B 主动反馈仍约 100 Hz，在线和有效计数持续增加；
3. LEFT 保持 B / `+1`，RIGHT 保持 A / `-1`；
4. RAM 软件零位、清除、左右隔离和重启失效语义不变；
5. `imp_start` 不创建任务或定时器，`imp_stop` 不停止控制任务；
6. 三轮 10 秒旧正弦阻抗运动与阶段 3 基线相当；
7. 每轮结束后两台电机均为失能请求状态；
8. BLE 断开重连后任务身份不变、周期计数连续；
9. TWAI 保持 RUNNING，关键错误和 RX missed 不增长；
10. 无 panic、assert、watchdog、brownout 或异常重启。

## 烧录和零位边界

烧录或复位会清除阶段 3 的 RAM 软件零位。控制任务必须能在零位无效时继续空闲
运行且不产生运动。执行旧阻抗实机回归前，需要双髋回到定义好的中立位，并重新
通过 BLE 执行左右软件归零。
