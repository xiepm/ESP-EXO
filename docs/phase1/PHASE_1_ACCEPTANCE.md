固件已烧录到实际 ESP32-S3，写入段校验通过并完成硬复位。首次烧录时 COM5 被遗留监视器进程占用；结束该进程后重新烧录成功，这不是固件故障。

| 测试 | 主要条件 | 结果 |
|---|---|---|
| UART 启动与控制台 | 连续观察 61 s；启动标志、`help`、`motor_type`、`can_status` | PASS |
| BLE GATT | 发现 `RobStride-CAN`、NUS 服务/RX/TX、命令响应、断开后重连 | PASS，重连 3.469 s |
| TWAI | 运行状态及发送/接收/总线错误计数 | PASS，所有错误计数为 0 |
| 执行器 A 主动反馈 | CAN ID `0x10`，观察 30 s | PASS，150 个有效样本 |
| 执行器 B 主动反馈 | CAN ID `0x20`，观察 30 s | PASS，150 个有效样本 |
| 阻抗启停 | 3 × 10 s，检查两电机运动、频率、相位、停止与失能 | PASS |

最终阻抗回归的严格表征结果：

- A/B 均有足够采样和运动跨度；
- 参考频率为 0.5 Hz；
- A/B 相位差约 170.38°；
- 三轮启停均完成，最终停止、上报关闭和双电机失能得到确认；
- 回归前后 TWAI 错误增量均为 0。

第一次严格表征运行中，前两轮功能检查通过，但串口共享的 200 ms 日志节流使第三轮 B 侧打印样本不足，测试脚本按严格条件判为未通过；复位后重新执行完整的 3 × 10 s 测试，采样覆盖和所有条件均通过。该现象属于观测日志采样密度，不是控制或总线失败。
