## 用户确认与控制语义

用户已确认：单向前抬，超过人体正角阈值，提供正向屈髋助力。
新增ANGLE_THRESHOLD模式4、策略4，版本1；保留原有透明、相位曲线和未实现AAN的编号。
左右使用已保存的出厂方向和本次RAM零位后的人体角度，不能使用CAN ID猜左右或比较电机原始角。

| 参数 | 范围与单位 | 含义 |
| --- | --- | --- |
| 前抬阈值T | 1–60°，精度0.01°；初始10° | 两侧共用数值，各自判断本侧角 |
| 触发助力M | 0–0.500 N·m，精度0.001 N·m | 复用最大附加力矩字段，不含基础速度阻尼 |
| 左/右等级 | 各0–100% | 该侧稳定力矩=M×该侧等级/100 |
| 退出回差 | 固定1° | q≤T−1°时该侧附加力矩立即为0 |
| 触发渐入 | 五次曲线200 ms | 每次触发从0开始，同时每10 ms上升最多0.010 N·m |

稳定输出是正的固定前馈力矩；实际上升时间取决于200 ms渐入和斜率限制，最大0.5 N·m可能需要更久。
例如T=10°、M=0.200 N·m、LEFT=100%、RIGHT=50%：左腿稳定建议+0.200 N·m，右腿+0.100 N·m。
建议不等于电机反馈力矩，也不等于人体感知力矩。

每轮START/反馈恢复后，每侧须先实际出现q≤T−1°，再出现q>T才触发；启动时已前抬不会直接给力。
q=T不触发；触发后在T−1°<q≤T区间保持，抑制阈值附近的反复开关。后伸负角不触发。
两侧独立触发，任一侧缺失有效传感输入仍按整机原有双侧门禁使策略清零。
不需要步态相位或置信度锁定，站立和单次前抬也可计算；仍使用同周期传感/步态序号、时间戳和activation epoch。
NaN/Inf、重复/回退时间或序号、电机故障、坐标代次变化和无效反馈清零并重新等待前抬。

执行分层保持：DISABLED不计算；SHADOW只计算建议，实际附加力矩为0；ACTIVE才可能合成真实附加力矩。
ACTIVE仍只能用DAMPING+CONSTANT基础控制；工程轨迹不能搭配ACTIVE。
只增加torque_ff，位置、速度、Kp、Kd不由此策略改变。仍只有唯一100 Hz任务和最终CAN出口。
固定工作区48字节（由静态断言限制≤64），无动态分配、日志、等待或CAN访问。

## BLE与网页

新增capability bit12；0.10.7身份必须声明该能力。0.10.6继续兼容。
旧GET_ASSIST_CONFIG、GET_ASSIST_TORQUE_LIMIT、0x16/0x19长度不变；旧SET不能选择新策略。

- 0x1D SET_ANGLE_ASSIST_CONFIG：12字节payload，原8字节配置+u16LE力矩mN·m+u16LE阈值0.01度。
- 0x0B GET_ANGLE_ASSIST_CONFIG：12字节payload，schema/flags、选择/活动阈值、回差、渐入ms、选择代数低8位、reserved=0。
- 所有帧≤20字节；业务层通过原IDLE维护锁一次保存模式、运行方式、等级、力矩与角度。
- 网页保存后逐项GET读回，核对阈值和0x07配置代次；ACK不单独作为已保存证据。

运动页新增“助力策略”选择：“步态相位曲线助力”或“角度阈值助力 · 单向前抬”，并保留透明观察。
选阈值策略后显示角度输入、触发力矩标签、设备保存值及运行锁存值。
切换策略只改草稿并切回SHADOW；必须另行保存、读回、START。
旧固件或断开连接时不会发送新opcode；提示需0.10.7，保存保持锁定。
助力配置仍保存在主控RAM，重启后恢复默认；出厂方向NVS和每次穿戴RAM零位的语义不变。
