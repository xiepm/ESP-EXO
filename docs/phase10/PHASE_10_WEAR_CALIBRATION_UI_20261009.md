# 2026-10-09 穿戴后零位校准入口

本轮为网页改造，不烧录、不执行软件或机械零位写入、不START。
阶段10真人SHADOW、ACTIVE 0%/5%/10%仍为NOT RUN。

## 变更

- 把原来藏在左右电机详情下方的归零入口移到「设置」顶部，标题为「穿戴后零位校准」。
- 首屏显示左右人体髋角、当前设备读回的软件偏置及左右对应核对；确认穿戴完成、静止中立位后，
  点击「校准并写入双髋零位」。出厂映射和原始读数折叠到下方。
- 使用既有CAPTURE_ZERO产品协议，依次写LEFT/RIGHT，再读回双方zeroValid/jointValid以及IDLE。
  只有双侧验证全部成功才显示本次写入成功时间，任何一步失败保留明确错误，不报告整体成功。
- 设备已有有效零位显示「设备已有零位」，不冒充本次穿戴已经校准。
  断连、主控Boot ID变化、零位失效、单侧重新写入或清零都会撤销本页双侧写入成功标记。
  双侧成功后消费当前中立位确认，再次校准需要重新确认。
- 保留待机、设备身份、有效反馈、左右人工核对及中立位门禁。
  零位仍在ESP32 RAM；主控重启后需重新校准，不永久写入RS01。
