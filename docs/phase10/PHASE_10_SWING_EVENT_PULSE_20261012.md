## 控制语义与坐标

本版将策略4（ANGLE_THRESHOLD）从持续阈值力矩改为version 3事件脉冲，不保留持续平台作为可选产品运行方式。
旧固件仍可被网页识别，但旧策略不能由新页面START；0.10.10与bit15确认后才开放新策略写入。

每侧独立执行：等待复位→等待新前抬越阈→确认本侧事件→一次脉冲→等待下一次复位。
一次已确认髋运动周期最多一次脉冲，无固定重复定时器；左右不强制交替或半周期关系。
这里的周期由本侧编码器运动事件定义，不宣称已获得足底接触或完整步态相位。

`u=(now-trigger_time)/Ta`，`tau_human=A*sin²(pi*u)`，仅`0≤u<1`可非零，结束后为0。
电机方向`s`由原`hip_joint`出口将人体力矩转换成电机力矩：`tau_motor=s*tau_human`。
策略不得再乘一次方向，不能按CAN ID猜左右。u只是本次脉冲进度，不使用它伪装步态相位。

事件必须来自新的本侧反馈：前抬越过人体正角阈值、正向速度≥5°/s、至少4个新反馈点、
确认跨度≥30 ms且越阈后继续前抬≥0.5°；确认超150 ms、回落或方向不符则消耗候选，等待复位。
复位需本侧角度≤复位角、位于−30°以上、连续新反馈跨度≥80 ms且至少5个反馈点；重复快照不能完成确认。
启动时已抬腿、停在阈值以上或阈值附近抖动，都不能直接触发或重复触发。

## 时长、峰值与更新

| 参数 | 范围 / 默认 |
| --- | --- |
| 触发角 | 1–60° / 10°，IDLE配置 |
| 复位角 | −30–59° / 触发角−2°；至少低于触发角1° |
| 前抬允许上限 | 至少高于触发角2°，最多90° / 触发角+20° |
| 100%等级申请峰值 | 0–5.000 N·m / 0.500；不得越过START锁存上限 |
| FIXED时长 | 100–2000 ms / 600 ms |
| PERIOD_SCALED比例r | 0.100–0.600 / 0.300 |
| Ta最短/最长 | 100–2000 ms且最短≤最长 / 150–1500 ms |
| 合理本侧周期下限/上限 | 300–5000 ms且下限<上限 / 400–3000 ms |

PERIOD_SCALED只使用本侧相邻有效事件间隔，连续两个合理间隔后才可信，采用0.25一阶平滑。
首事件及仅一个间隔只预热；异常短间隔拒绝且不移动有效锚点；过长间隔、超过估计50%的节律突变或反馈复位撤销可信度。
长时间无事件使旧周期过期，但不会据此生成任何新事件或脉冲。
`Ta=clamp(r*T,Ta_min,Ta_max)`；周期不可信时该事件不生成比例时长助力。FIXED用于先验证事件门禁。

申请峰值先乘本侧等级。继承既定10 N·m/s上升约束：sin²最大正斜率为`pi*A/Ta`，
故本次冻结`A=min(申请峰值*等级/100,10*Ta/pi)`，不在曲线外追加滞后滤波或延长脉冲。
完整5 N·m要求Ta至少约1.571秒；600 ms脉冲100%等级最多约1.910 N·m。
网页显示申请值和实际冻结峰值，并明确显示速率限幅。

纯时长/峰值参数可在IDLE或RUNNING原子更新，同一控制周期使用其已复制的配置。
已开始的A和Ta始终冻结；后续新事件使用更新参数。START最大力矩、百分比、执行状态和触发阈值仍只能IDLE设置。
角度窗口收紧立即生效；放宽窗口不能放宽当前脉冲已冻结的安全边界，只影响下次事件。
改变复位角撤销旧READY/候选事件与周期可信度，必须按新复位规则重新确认；当前脉冲仍保留冻结A/Ta及更严格窗口。
时长/峰值为一个16字节配置对象，窗口为独立配置对象，网页对两者分别ACK并读回，不把ACK单独当作保存证据。

## 提前退出和执行门禁

- STOP/disarm推进activation epoch并丢弃旧结果，不把剩余脉冲强行放完。
- 反向速度<−2°/s或新反馈角度单帧下降>0.25°，立即清零并等待新复位。
- 新反馈连续确认速度绝对值≤2°/s、每帧角差≤0.05°，跨度≥100 ms且至少5帧，按停止/低速保持提前清零。
- 超出有效角度窗口，立即清零并等待复位。
- 反馈失效、超过50 ms、NaN/Inf、计数/时间回退、控制时间重复/回退、坐标epoch变化或电机故障，取消旧脉冲/历史。
- 任一侧所需传感输入失效仍受整机双侧门禁保护；恢复后重新复位和采集事件。

SHADOW计算完全相同的脉冲建议但实际附加力矩为0；ACTIVE仍要求DAMPING+CONSTANT，
只叠加torque_ff并经现有唯一CAN出口。没有新增100 Hz任务、CAN旁路、堆分配或主动位置轨迹。
固定策略预算由64改为256字节；本策略实际工作区240字节，单侧状态112字节。
真机执行时间、栈余量、停止实际延迟和BLE负载尚需测量。

## 协议与网页

BLE v1保留20-byte上限及旧操作码长度，新增bit15 `SWING_EVENT_PULSE`（v1能力位已用至bit15）。
GET_ANGLE_ASSIST_CONFIG使用schema2读阈值，旧回差/渐入字段置0表示不适用；schema1旧解析继续保留。

| opcode | 请求载荷 | 响应 / 作用 |
| --- | --- | --- |
| 0x20 GET_PULSE_TIMING | 0 | 16字节：schema/mode、峰值mN·m、固定ms、r千分数、Ta上下限ms、T上下限ms |
| 0x21 SET_PULSE_TIMING | 16 | 原子更新下一事件参数，ACK；不能提高START上限 |
| 0x22 GET_PULSE_WINDOW | 0 | 8字节：schema/reserved、复位有符号0.01°、前抬上限0.01°、事件速度0.01°/s |
| 0x23 SET_PULSE_WINDOW | 4 | 复位角i16、上限u16，ACK；与触发阈值联合校验 |
| 0x24 GET_PULSE_STATUS | side | 16字节：side/state/flags/退出原因、事件/脉冲计数、冻结时长、周期、峰值、u万分数 |

脉冲状态由控制任务发布到诊断副本，BLE不跨任务访问实时工作区；网页低频查询不参与实时控制。
运动页增加两种时长模式、申请峰值、复位与窗口、左右独立状态；未连接只是草稿，保存/START受真实读回门禁约束。
