# 0.10.9 可选沿用穿戴零位

状态：`SOFTWARE PASS; FLASH PASS; IDLE / MOTION OUTPUT 0; WEB INFO PENDING; SAVED ZERO HARDWARE HIL NOT RUN`。用户确认本轮动力断开后已从冻结产物烧录；部署证据独立记录，冻结manifest不回写。见[0.10.9部署](PHASE_10_0_10_9_DEPLOYMENT_20261010.md)。

用户最新要求覆盖此前“每次穿戴都重新归零”的流程：可以选择沿用上次设置，也可以选择不沿用。本版新增主控NVS候选，不从历史日志补写旧零位。

## 用户流程

设置页保留出厂方向标定，穿戴零位提供“沿用上次零位 / 重新校准”。

- 重新校准：确认双髋中立静止后采集RAM零位。0.10.9默认勾选“保存本次零位供下次沿用”；可取消，只用于本次，旧候选保留。
- 沿用上次：先读主控候选和人体角预览，确认本次中立静止后，再恢复双侧RAM并读回。保留原偏置，不把当前位置强制归零。
- 忘记已保存零位：明确确认后删除候选；本次RAM零位和出厂方向不变。

无记录、记录损坏、映射/方向不符、反馈无效、非REST、运动或故障时不能沿用；任一侧中立偏差超过5°时要求重新校准。5°为当前固定沿用门限，与运动页10°助力阈值不同，不是人体试验结论。安装、机械零点或佩戴位置改变后应重新校准；同ID同槽位更换电机不能仅靠配置绑定识别。

0.10.8及更旧固件仍可用原RAM校准，新选项显示升级说明，不发送未知命令。旧固件没有持久候选，复位后无法自动恢复上一次未保存的RAM偏置。新功能首次使用需要校准并保存一次。

## 固件与协议

`exo_wear_zero.c`使用固定20字节blob，绑定LEFT/RIGHT、执行器、CAN ID、方向及格式版本，两侧成对提交/读回；无新控制任务。NVS仅在初始化/IDLE维护中读写，100 Hz任务不访问NVS。产品方向示教BEGIN先撤销旧候选，防止调整安装但符号相同后误沿用。

启动只加载候选缓存，生效RAM零位仍无效。恢复要求双电机REST、无故障、有效连续位置、反馈不超过50 ms、速度不超过5°/s及操作者确认。恢复前后核对epoch、序号和位移变化，失败不发布半侧；成功在关节短临界区一次发布双侧。

保存RS01周期电机偏置（deg），用1440°周期差投影到本次连续坐标，不复用旧启动的圈数、epoch或时间戳。人体角/速度/力矩仍统一使用出厂方向。所有零位操作不发送CAN使能、运动或机械置零，不自动START。

BLE v1新增bit14 `SAVED_WEAR_ZERO`。0x1E为单侧只读候选/预览，0x1F为双侧SAVE_CURRENT/RESTORE/FORGET和明确确认字节。只读响应固定20字节，偏置/预览用i32毫度，缺失INT32_MIN。旧请求不变；网页按能力决定命令，写后读回，不用浏览器存储冒充主控保存。
